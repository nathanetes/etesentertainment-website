# etesentertainment.com

Company site for Etes Entertainment LLC and its label, A1 Records.

Static HTML, deployed with Cloudflare Pages from the `main` branch. No build step.

- `index.html`: the site, including Organization schema for Etes Entertainment LLC and A1 Records
- `site.js`: barcode drawing and the copy-address button
- `fonts/`: self-hosted Archivo and IBM Plex Mono (SIL Open Font License, see the OFL files)
- `_headers`: security headers and content security policy
